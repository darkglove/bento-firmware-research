# Current research

The research is no longer limited to the first 1.6.1 title patch. Start with the [November 2026 research guide](research/README.md).

The current analysis baseline is 1.6.8. The guide covers architecture, versions, audio, files, sequencing, MIDI/USB, storage, startup, graphics, controller input and recovery. It includes a [74-checkpoint index](research/CHECKPOINTS.md), [decoded reference tables](reference/README.md), and explicit [evidence limits](research/EVIDENCE.md).

The old tutorial's offsets and build procedure remain specific to [1.6.1](TUTORIAL.md). Several earlier open questions have since been narrowed: core responsibilities, controller reverb, native UI rendering and settings persistence now have further evidence. The complete loader policy, physical timing and the final controller-to-audio-amplitude check remain open.
