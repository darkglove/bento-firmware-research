# Traced pin configurations, 1.6.1 baseline

These facts come from the recorded CM7, CM4 and disk-mode boot register traces for the image also labeled 1.6. Alternate-function names were interpreted using the processor pin tables. This is **only what the trace reached**, not a complete schematic or a claim that every peripheral was initialized.

`?AF0` on debug pins denotes the reset default, not a deliberate firmware configuration. Later 1.6.8 findings must be version-checked separately. The extraction harness and original trace files are not included.
